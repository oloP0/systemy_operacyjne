Systemy Operacyjne

Systemy Operacyjne to strona edukacyjna, którą stworzyłem samodzielnie w celu przedstawienia najważniejszych informacji dotyczących systemów operacyjnych. Projekt powstał jako sposób na uporządkowanie i pokazanie w praktyce wiedzy związanej z systemami, którą rozwijam podczas nauki na kierunku Technik Informatyk.

Strona skupia się przede wszystkim na najpopularniejszych systemach operacyjnych oraz przedstawia ich najważniejsze cechy, zastosowania i różnice. Zależało mi na tym, żeby informacje były przedstawione w prosty i czytelny sposób, a sama strona nie była tylko zwykłym tekstem.

Co znajduje się w projekcie?

Na stronie znajdują się informacje dotyczące między innymi Windows, Linux oraz macOS. Każdy z systemów został przedstawiony osobno, wraz z podstawowymi informacjami na jego temat.

Projekt zawiera również informacje dotyczące działania systemów operacyjnych, ich zastosowania oraz podstawowych elementów związanych z ich funkcjonowaniem.

Jednym z ważniejszych elementów strony jest interaktywny quiz, dzięki któremu użytkownik może sprawdzić swoją wiedzę. Quiz został przygotowany przy użyciu JavaScript i reaguje na odpowiedzi użytkownika.

Zależało mi również na tym, żeby strona była wygodna w użyciu na różnych urządzeniach. Dlatego przygotowałem responsywny wygląd, który dostosowuje układ strony do wielkości ekranu.

Technologie

HTML – struktura strony i zawartość poszczególnych sekcji

CSS – wygląd strony, układ elementów, responsywność i stylowanie

JavaScript – interaktywny quiz oraz funkcje strony

Vercel – wdrożenie i udostępnienie strony online

Najważniejsze elementy

• informacje o systemach Windows, Linux i macOS
• opisy i charakterystyka systemów operacyjnych
• interaktywny quiz sprawdzający wiedzę
• responsywny wygląd strony
• uporządkowany podział informacji
• elementy interaktywne wykonane w JavaScript
• strona dostępna online

Moja praca przy projekcie

Projekt stworzyłem samodzielnie, zaczynając od przygotowania struktury strony, następnie zajmowałem się wyglądem oraz dodawaniem funkcjonalności.

Podczas pracy nad projektem ćwiczyłem przede wszystkim HTML, CSS i JavaScript, a także organizację większej ilości informacji na stronie. Quiz pozwolił mi wykorzystać JavaScript nie tylko do tworzenia prostych elementów strony, ale również do stworzenia interaktywnej funkcji dla użytkownika.

Projekt był również okazją do przećwiczenia tworzenia responsywnych stron internetowych oraz wdrażania gotowego projektu online.

Czego nauczył mnie projekt?

Tworząc stronę, rozwinąłem umiejętności związane z tworzeniem stron internetowych, projektowaniem ich wyglądu oraz dodawaniem interaktywnych elementów.

Najważniejsze było dla mnie jednak połączenie nauki z praktyką. Zamiast tylko uczyć się teorii dotyczącej HTML, CSS i JavaScript, mogłem wykorzystać ją do stworzenia kompletnego projektu, który można normalnie otworzyć i wykorzystać.

Technologie: HTML, CSS, JavaScript, Vercel
